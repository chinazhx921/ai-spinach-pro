# AI-Spinach Pro 4.0 (全彩种矩阵预测版)

## 4.0 更新日志
* **多维度切换**: 新增顶栏选择器，支持 `双色球(6+1)`、`大乐透(5+2)`、`福彩3D(3)` 实时一键切换。
* **动态张量网络 (Dynamic Tensor)**: 
  * LSTM 神经网络现已升级，会根据你选择的彩种**动态调整输入层和输出层的神经元数量**。
  * 例如：双色球预测 6 维输出，大乐透预测 5 维输出，福彩 3D 预测 3 维输出（并允许数字重复）。
* **专属 UI 渲染**:
  * 不同的彩种在出号时将适配不同的展示逻辑（福彩 3D 使用绿球，大乐透使用专属 5+2 占位布局）。
* **Worker 代理同步升级**:
  * 后端爬虫代理 (`worker.js`) 现已支持 URL Query 传参 (`?type=...`)，能够智能抓取并清洗不同彩种的数据格式。

## 部署说明 (请务必更新 worker)
1. 将 `index.html`、`app.js`、`styles.css` 提交至你的 GitHub 以更新 Pages。
2. 登录 Cloudflare Workers，**将最新的 `worker.js` 代码复制粘贴进去并重新部署**。
3. 如果尚未绑定正式的第三方彩票 API 密钥，Worker 会在底层自动生成高仿真的 Mock 结构数据供前端张量网络推演测试，页面绝不会崩溃。
