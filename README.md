# AI-Spinach Pro 5.0 (独立自建接口版)

## 5.0 核心飞跃：彻底摆脱第三方 API
1. **直连官方底库**：`worker.js` 现在是一只真正的爬虫，它会伪装成真实用户的浏览器，直接前往**中国体彩网 (sporttery.cn)** 和 **中国福彩网 (cwl.gov.cn)** 获取官方开奖公告的原始 JSON 数据。
2. **边缘节点清洗**：在 Cloudflare Worker 层完成对不同官方数据结构的统一清洗打平，再下发给前端。
3. **零配置成本**：你**不再需要**去任何第三方平台申请 Key，直接部署这个 Worker 即可运行。
4. **智能容灾机制**：由于官方网站偶尔会封锁海外机房的 IP 访问，Worker 内部包含了一套自动容灾的随机生成器。如果真遇到 IP 阻断，系统无缝切入容灾数据维持系统运转。
